One joke pickup line, aimed at a CAPTCHA — the AI that keeps asking you to
prove you're not a robot. My line flips the test: the speaker isn't
struggling to pass it, he's been showing off for it for an hour.

> Are you a CAPTCHA? Because I've been picking traffic lights for an hour — not to prove I'm human, but to impress you.

## How it works

`main.ts` (Node 22, stdlib-only, deterministic) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else is written, nothing is read
from the network, and the output is identical on every run.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
